### Retrieval design consequence

Notes/Files/Knowledge являются reusable technical seams, но не managed canonical store. Production adapter должен индексировать exact eligible published Git revision в inactive/shadow storage, возвращать `document_id + document_revision_sha + section`, выполнять fresh ACL и читать канон через GO. Это соответствует ADR-03; pgvector/ANN/FTS/model parameters не выбраны: `/Users/antonsmychkin/Documents/Job/corp_ai_db/specs/corporate-kb/adr/ADR-003-retrieval-adapter.md:14-23`, `/Users/antonsmychkin/Documents/Job/corp_ai_db/specs/corporate-kb/components/retrieval-indexing.md:7-15`.

Обязательные index metadata отсутствуют в текущем generic file path: `space_id`, `document_revision_sha`, `snapshot_sha`, `main_generation`, `index_profile_version`, `dependency_hash`, stable section/range и immutable attachment revision. Нужны отдельный CI writer и managed `kb_index`, а не UI `/process/file` как production writer.
